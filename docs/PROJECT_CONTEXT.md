# LearnQuest LMS - Project Context

## Overview

LearnQuest is an AI-powered Adaptive Learning Management System (LMS) developed as a BSIT Capstone Project.

The system is designed for **Grade 11 and Grade 12 STEM students of Kapitolyo High School** to improve competency mastery in **Science subjects** through Artificial Intelligence, Learning Analytics, and Adaptive Learning.

The system combines:

- Artificial Intelligence
- Bayesian Knowledge Tracing (BKT)
- Learning Analytics
- Adaptive Learning
- Personalized Recommendations

---

# Main Objectives

The system should:

- Deliver learning materials.
- Generate AI-powered lesson summaries.
- Generate AI-powered adaptive quizzes.
- Track student competency mastery.
- Recommend learning materials.
- Provide personalized feedback.
- Monitor student progress.
- Assist teachers through analytics dashboards.

# Mastery Estimation

The system uses:

Bayesian Knowledge Tracing (BKT)

NOT Random Forest.

NOT Deep Learning Knowledge Tracing.

NOT Markov Decision Process.

BKT estimates mastery using:

- Quiz answers
- Correct/incorrect responses
- Learning attempts

Parameters:

```
P(L0)
P(T)
P(G)
P(S)
```

The computed mastery determines:

- Quiz difficulty
- Learning recommendations
- Personalized feedback
- Competency level

---

# Adaptive Quiz Generation

Teachers upload learning materials.

The AI automatically:

- Reads the material.
- Creates lesson summaries.
- Generates multiple-choice quizzes.
- Adjusts question difficulty according to BKT mastery.

Teachers do NOT create quizzes manually.
